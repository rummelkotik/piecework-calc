# Пак минималистичных SVG-иконок сантехники (жирные линии)

Минималистичный набор иконок в стиле outline с **увеличенной толщиной линий**.

**Размер:** 24×24  
**Stroke:** 2.5  
**Цвет:** currentColor (наследует цвет текста)

## Список иконок

| Файл | Описание |
|------|----------|
| `toilet.svg` | Унитаз |
| `bathtub.svg` | Ванна |
| `shower-tray.svg` | Душевой поддон |
| `shower-cabin.svg` | Душевая кабина |
| `shower-partition.svg` | Душевая перегородка |
| `sink.svg` | Раковина / умывальник |
| `bidet.svg` | Биде |
| `faucet.svg` | Смеситель |
| `shower-head.svg` | Душевая лейка |
| `towel-rail.svg` | Полотенцесушитель |

## Использование

```html
<img src="toilet.svg" alt="Унитаз" width="24" height="24">
```

или напрямую вставляй SVG-код и меняй цвет через CSS (`color` / `stroke`).
