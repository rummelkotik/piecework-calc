# 💼 Worklog Pro (Piecework Calculator)

> Автономный веб-сервис для специалистов со сдельной и посменной оплатой: оперативный учет выработки, аналитика доходов, учет налоговых ставок и расчет метрик эффективности.

🔗 **Live Demo:** [piecework-calc.vercel.app](https://piecework-calc.vercel.app)

---

## 📌 Ключевые возможности

- ⏱ **Учет смен и выработки:** Быстрое внесение записей по сменам, ставкам и выполненным услугам без перегруженных таблиц.
- 📊 **Финансовая аналитика:** Автоматический расчет чистой прибыли, вычет налогов и динамический расчет среднего заработка за рабочий день.
- ⚡ **Легковесная архитектура:** Минимальное количество внешних зависимостей, быстрая загрузка и мгновенный отклик интерфейса.
- 📱 **Mobile First UI:** Полная адаптивность интерфейса под смартфоны для оперативного ввода данных прямо на рабочем месте.

---

## 🛠 Технологический стек

- **Frontend:** Vanilla JavaScript (ES Modules), HTML5, кастомный CSS (CSS Variables, Flexbox/Grid)
- **Backend / Хранение:** Node.js, Express, SQLite
- **Деплой:** Vercel
